# Yelp Rating Predictor

Merges six Yelp datasets (businesses, reviews, users, check-ins, tips and photos) and fits linear regression models to see which restaurant features predict a Yelp star rating.

## Getting the data

The datasets aren't stored in this repo because they're large. They come with Codecademy's Yelp Rating Regression Predictor project. Put these six files in this folder next to the notebook:

- `yelp_business.json`
- `yelp_review.json`
- `yelp_user.json`
- `yelp_checkin.json`
- `yelp_tip.json`
- `yelp_photo.json`

Then run the notebook from this folder.
