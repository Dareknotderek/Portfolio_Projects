# Stack Overflow Developer Survey

A staffing-agency scenario: a fast-growing client wants to know what kinds of developers are out there and what they earn. The notebook cleans the Stack Overflow developer survey data, handles its missing values, and charts developers by country, undergraduate major, and pay by years of experience.

## Getting the data

The dataset isn't stored in this repo. It comes from Codecademy's handling-missing-data course:

https://static-assets.codecademy.com/Courses/handling-missing-data/stackoverflow-project/developer_dataset.csv.zip

Download it, unzip it, and put `developer_dataset.csv` in this folder next to the notebook. Then run the notebook from this folder.
